# agsaver.ca

Marketing site for AgSaver, the farm machine app for iPhone, iPad and Apple Watch.
Static HTML served by GitHub Pages at https://agsaver.ca.

Pages are generated from `_build/build.py` (header, footer and all page content live there).
Edit that file and run:

    python3 _build/build.py

Images are in `img/` (App Store screenshots in `img/shots/`, converted to WebP).
